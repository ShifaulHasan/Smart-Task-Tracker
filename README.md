# ✅ Smart Task Tracker

**Smart Task Tracker** is a lightweight web app for managing daily tasks. Users can add tasks, delete them, and mark them as complete through a simple, responsive interface. It is built with plain **HTML, CSS, and JavaScript**, and focuses on **DOM manipulation, event handling, and front-end development practice**.

---

## ✨ Features

- ➕ Add new tasks
- 🗑️ Delete tasks
- ✔️ Mark tasks as complete
- 📱 Simple, responsive interface
- ⚡ No frameworks or libraries, just vanilla JavaScript

---

## 🧰 Tech Stack

| Technology | Purpose                          |
|------------|----------------------------------|
| HTML5      | Page structure                   |
| CSS3       | Styling and responsive layout    |
| JavaScript | Task logic, DOM and event handling |

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/ShifaulHasan/Smart-Task-Tracker.git
   ```

2. **Open the project folder**
   ```bash
   cd Smart-Task-Tracker
   ```

3. **Run the app**
   Open `structure.html` in any modern web browser (just double-click it). No installation or server needed.

---

## 📖 How to Use

1. Type a task in the input box and click **Add**.
2. Click a task to mark it as **complete**.
3. Use the **Delete** button to remove a task.

> 📝 *Adjust these steps to match your exact buttons and behavior.*
